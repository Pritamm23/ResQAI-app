# ResQAI-app

An AI-powered emergency response system designed to reduce response time during critical situations. It uses real-time location tracking, smart ambulance dispatching, and predictive AI to connect patients with the nearest available emergency services quickly and efficiently.

This needs to be downloaded at first for smooth working:
1.next
2.react
3.react-dom
4.leaflet
5.react-leaflet
To start first download the app req by the easy command "npx create-next-app@latest" then add the 3 given files under the /app
